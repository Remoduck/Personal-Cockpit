What is GitHub?

GitHub is a place to store Git repositories and collaborate on changes. It adds tools for sharing code, reviewing contributions, and tracking work around a project.

Repository

A project space containing files and their change history.

Commit

A saved snapshot of changes, usually with a short message.

Branch

A separate line of work used to develop changes safely.
